Colors of the Day facts

A daily colour memory game for iPhone.

Colors of the Day is a daily puzzle game for iPhone, made by Flux76. Every day, all players get the same five colours. Each colour is shown for 5, 4, 3, 2 and 1 seconds in turn, after which the player recreates it from memory with a colour picker. Each round scores 0 to 100 points, for a maximum of 500 a day, and a game takes about two minutes. The daily puzzle and sharing are free, and there are no ads. The app is in development and available as a beta on TestFlight.
